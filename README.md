# Sales_analysis-P2-decodelabs
Overview

This project performs Exploratory Data Analysis (EDA) on a sales dataset to identify customer purchasing patterns, revenue trends, payment preferences, referral sources, and key factors influencing total sales.

Objectives

- Analyze sales performance
- Understand customer behavior
- Identify popular products
- Study payment method preferences
- Examine referral source effectiveness
- Detect outliers in sales data
- Analyze correlations between numerical features

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

Analysis Performed

Product Analysis

- Counted purchases for each product category.
- Identified the most frequently purchased products.

Payment Method Analysis

- Compared usage of different payment methods.
- Determined customer payment preferences.

Referral Source Analysis

- Evaluated customer acquisition channels.
- Compared referral effectiveness.

Revenue Analysis

- Calculated total revenue generated from sales.

Visualizations

- Product Distribution
- Payment Method Distribution
- Referral Source Distribution
- Total Price Histogram
- Total Price Boxplot
- Correlation Heatmap

Key Findings

- Unit Price showed the strongest correlation with Total Price.
- Quantity purchased significantly influenced Total Price.
- Instagram generated the highest number of referrals.
- Online payments were the most preferred payment method.
- Several high-value outliers were identified in Total Price.
